# KeyboardClean · 键盘清洁

清洁 Mac 键盘时暂时屏蔽按键，清洁完可用触控板或鼠标点击解锁。

## 功能

- 一键开始清洁，手动点击解锁。
- 在 HID 事件层拦截普通按键、修饰键及媒体键事件。
- 鼠标和触控板保持可用。
- 没有定时自动解锁；关闭或退出应用会解除拦截。
- 完全本地运行，不记录按键内容、不联网。

## 使用

解压安装包，将「键盘清洁.app」放入「应用程序」。第一次打开后按系统提示授权，再点击「开始清洁」。清洁完点击「清洁完成 · 点击解锁」。

详细步骤与常见问题：[使用教程](docs/使用教程.md)。

## 系统与限制

当前安装包面向 Apple 芯片 Mac，部署目标为 macOS 13 或更新版本；目前实际试用环境为 macOS 27，其他版本尚未验证。暂不提供 Intel 安装包。

电源键、Touch ID 以及由底层系统或其他软件独立处理的快捷键无法保证屏蔽。开始后先在空白文本框试按，确认本机拦截生效，再清洁。避免擦碰电源键。

macOS 27 的授权入口是「隐私与安全 → 设备控制和数据访问」，较早系统对应「辅助功能」。该授权范围由 macOS 定义；本应用只用它建立键盘事件拦截，不读取其他应用内容。

## 分发状态

当前准备的安装包采用临时签名，未经过 Apple 公证。其他电脑的首次打开与授权体验尚未验证。不要关闭系统整体安全保护来安装；如系统拒绝打开，可查看系统设置的具体提示或自行从源码构建。

## 从源码构建

安装 Xcode Command Line Tools，并确保有 Python 3，然后运行：

```sh
zsh build.sh
```

输出位于 `dist/`。默认临时签名；有自己的代码签名身份时可指定：

```sh
KEYBOARD_CLEAN_SIGN_IDENTITY="你的代码签名身份" zsh build.sh
```

临时签名的版本重新构建后可能需要重新授权。源码和图标使用 AI 辅助开发制作。
