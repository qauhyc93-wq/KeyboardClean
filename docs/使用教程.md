# 使用教程

## 1. 安装

下载 Release 中的 Apple 芯片安装包，解压后将「键盘清洁.app」放入「应用程序」文件夹，再打开。当前版本未经过 Apple 公证；系统可能提示无法验证开发者。按 macOS 提供的具体提示处理，不需要关闭全局安全保护。

## 2. 第一次授权

应用需要辅助功能权限来屏蔽键盘输入。

1. 打开「系统设置 → 隐私与安全」。
2. macOS 27 进入「设备控制和数据访问」；较早版本进入「辅助功能」。
3. 找到「键盘清洁」并打开开关。若没有，点击 `+`，选择「应用程序」里的这个 App。
4. 系统要求验证时，用 Touch ID 或密码确认。
5. 返回应用点击「开始清洁」。若权限尚未生效，退出应用后重新打开。

## 3. 开始清洁

点击「开始清洁」，界面显示「键盘已锁定，可以清洁了」。先在没有重要内容的空白文本框试按，检查普通按键、Fn 和输入法切换是否都被挡住，再擦拭键盘。

鼠标和触控板仍可点击其他地方，清洁时只擦键盘。电源键和 Touch ID 无法保证屏蔽。

## 4. 解锁

清洁完可用触控板或鼠标点击解锁。点击「清洁完成 · 点击解锁」，界面显示键盘已解锁。也可以用鼠标关闭应用窗口。

没有自动解锁倒计时。若系统中断拦截，应用会恢复解锁状态。

## 常见问题

**点击开始后提示权限不足**：核对授权的是「应用程序」里的同一个 App，打开开关后重启应用。

**个别按键还能触发功能**：可能由底层系统或其他软件独立处理。先停止清洁，记录系统版本、键盘型号和具体按键，在项目 Issue 中反馈，不要附带密码、个人输入内容或完整系统日志。

**更新后需要重新授权**：临时签名可能随构建变化。新版本与旧权限不匹配时，按系统提示重新添加应用。
